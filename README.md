#  Design to Dev – Vanilla CSS Branch

> 🛠 **This branch is currently under development and not yet complete.**
>Certain styles or sections may be missing or incomplete.



Project: Sprint 1 Layout Challenge – ITACADEMY
Description: Developed a responsive web layout using Vanilla CSS  and HTML.
Tools Used: HTML5, CSS3 (no frameworks or preprocessors)..

## 📌 Goal
Replicate a design using just native HTML5 and CSS3, with a focus on:

Semantic HTML structure
Clean, reusable CSS
Responsive design via media queries
Good practices without utility classes or nesting

## 🚀 Getting Started

1. **Clone the repo and switch to this branch:**

```bash
git clone https://github.com/BauveR/Sprint-1.git

```

📋 Requirements - 🛠️ Installation

No installation or additional dependencies are required.

2. **Execution:**

Open `index.html` in your browser to acces the site, or use **Live Server** in VS Code for auto-refresh:

```bash
# VS Code users:
Right-click on index.html → "Open with Live Server"
```
